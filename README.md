\# 🚀 React DevOps CI/CD Project



A complete DevOps deployment project built using React JS, Docker, Jenkins and AWS EC2.



This project demonstrates how modern CI/CD pipelines work in real-world deployment environments.



\---



\# 📌 Technologies Used



\- ⚛ React JS

\- 🐳 Docker

\- 🔧 Jenkins

\- ☁ AWS EC2

\- 📂 GitHub

\- 🌐 Nginx



\---



\# ⚙ CI/CD Workflow



```text

Developer

&#x20;  ↓

GitHub Repository

&#x20;  ↓

Jenkins Pipeline

&#x20;  ↓

Docker Build

&#x20;  ↓

AWS EC2 Deployment

```

\# 🐳 Docker Deployment



The React application is containerized using Docker and deployed automatically through Jenkins pipeline.



Docker responsibilities:



\- Build React application image

\- Run containerized deployment

\- Manage application runtime



\---



\# 🔧 Jenkins Automation



Jenkins pipeline automatically:



\- Pulls latest code from GitHub

\- Builds Docker image

\- Stops old container

\- Deploys updated container on AWS EC2
